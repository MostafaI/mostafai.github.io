# mostafai.github.io

Personal academic website for Mostafa Ismail — served at https://mostafai.github.io

## Pages
- `index.html` — Home (about, news, research, education summary)
- `education.html` — degrees and coursework
- `experience.html` — research and professional experience
- `projects.html` — projects with figures
- `publications.html` — journal articles, proceedings, book chapter, thesis, abstracts
- `awards.html` — honors and awards
- `contact.html` — contact details

The **CV** nav link opens `assets/cv.pdf` directly.

## Other files
- `style.css` — single shared stylesheet (academic style, blue theme)
- `assets/` — images, figures, and `cv.pdf`
- `sitemap.xml`, `robots.txt` — SEO / search-engine discovery
- `.nojekyll` — disables Jekyll so all files (including images) are served as-is
- `googlef181d0ae6fc000b0.html` — Google Search Console verification

## Edit & publish
Edit the HTML/CSS, then:

```
git add -A && git commit -m "..." && git push
```

The site auto-deploys via GitHub Pages on push to `main` (live within ~1 minute).
